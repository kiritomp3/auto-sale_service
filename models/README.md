# Пресеты моделей для try-on (наложение одежды)

Эта папка содержит заготовки фотомоделей в позах, на которые накладывается одежда.

## Как добавить модель

1. Положите фото модели (jpg/png, вертикальное, человек в полный рост) в эту папку.
2. Добавьте запись в `catalog.json`:

```json
{
  "id": "female_front_standing",   // уникальный идентификатор (латиницей)
  "name": "Девушка, фронтально, стоя",
  "gender": "female",               // female | male | unisex
  "pose": "стоя, фронтальный ракурс",
  "file": "female_front_standing.jpg"  // имя файла в этой папке
}
```

Папка монтируется как статика по пути `/models/<file>`, поэтому `preview_url`
в ответе API формируется автоматически. При необходимости можно задать
`preview_url` явно (например, ссылку на CDN) — тогда поле `file` для превью не используется.

Эндпоинт `GET /tryon/models` возвращает этот каталог фронтенду.
