# Проверка генерации 12 ноября 2026

## Подтверждённые факты

- Production API использовал `b003fe8`, Gemini 3.8 Flash и GPT Image 2 через Kie.ai.
  Старого Gemini 2.5 в работающем контейнере нет.
- Сохранённая неуспешная задача завершилась на vision с application `code=400`
  внутри HTTP 200; исходное сообщение провайдера не сохранялось. Сам по себе
  этот код не устанавливает причину и не доказывает снятие модели с поддержки.
- Один минимальный текстовый запрос вернул HTTP 200 / `code=503` / Service
  Unavailable. Повторный запрос на том же канале с текущим payload прошёл.
- Vision на безопасном фото из репозитория прошёл. Однократный vision replay
  исходного фото неуспешной задачи также прошёл; фото и содержимое ответа
  не выводились в инструмент или интерфейс.
- Модели и каналы не менялись. Отказ провайдера носил перемежающийся характер;
  исторический `400` в момент проверки не воспроизводился.

## Исправление

- Полный отказ изображений теперь приводит к `failed`. Подстановка исходного
  фото на белый фон больше не выдаётся за успешную генерацию.
- При частичном успехе возвращаются только реальные изображения в исходном
  порядке. `image_generation_errors` сохраняется в `JobState` и Redis.
- Ошибки изображений, описаний и задачи переводятся в безопасные сообщения.
  Signed URL, ключи, промпты и исходные ответы провайдера не копируются в публичные
  поля. Диагностические логи сохраняют тип, `reason` и `provider_code`.
- Известные ошибки авторизации, баланса, ограничений и неподдерживаемого канала
  имеют разные сообщения. Временные application errors сохраняют bounded retries
  из production-исправления `b003fe8`.
- Документация приведена к фактическому Gemini 3.8 и `KIE_AI_API_KEY`.

## Проверка

`python -m unittest discover -s tests -v`: 41 тест пройден. Регрессии проверяют
полный и частичный отказ, отсутствие ложного результата, сериализацию ошибок,
сохранение provider code и отсутствие утечки signed URL/ответов провайдера.

Один полный smoke нового кода выполнен в изолированном Python-процессе внутри
работающего контейнера, с `TemporaryDirectory`, безопасным фото из репозитория
и `n_cards=1`: vision → GPT Image 2 → описание. Production-файлы, Redis и
пользовательские задачи не изменялись.

Результат: `status=done`, одна реальная PNG-карточка 1024×1536, 2 368 233 байта,
`image_generation_errors=[]`, `metadata_error=null`. Изображение проверено
визуально. Платные вызовы после этого smoke не повторялись, кроме уже согласованного
однократного vision replay для исходной неуспешной задачи.
