# Модели генерации

Анализ фотографий, тексты карточек, тексты для примерки и AI-чат Ozon используют
**Google Gemini 2.5 Flash через Kie.ai**. Прямых запросов к Claude в рабочем
контейнере больше нет. Старый клиент Claude сохранён для совместимости, но не
подключён к сервисам.

Это смена поставщика модели с Anthropic на Google, а не полный уход от шлюза
Kie.ai. Генерация изображений по-прежнему использует GPT Image 2 через Kie.ai.

## Настройка

Требуется существующая переменная `KIE_AI_API_KEY`. Ключи `GEMINI_API_KEY` и
`OPENAI_API_KEY` для этого маршрута не используются. Секреты задавайте в окружении
сервера; не добавляйте их в коммиты.

После обновления кода сервис необходимо пересобрать и перезапустить:

```sh
docker compose up -d --build wb-cards-api
```

## Формат запросов

- Текст: `https://api.kie.ai/gemini-2.5-flash/v1/chat/completions`.
- Авторизация: `Authorization: Bearer …`.
- Фото сначала загружается в файловое хранилище Kie.ai, затем передаётся как
  HTTP(S)-ссылка в блоке `image_url`. Большие встроенные data URL шлюз отклоняет.
- Ответ читается из `choices[0].message.content`; пустые, обрезанные ответы и
  ошибки внутри HTTP 200 не считаются успешной генерацией.
- При временных HTTP-ошибках выполняется до четырёх попыток с паузами.

Документация: [Gemini 2.5 Flash в Kie.ai](https://docs.kie.ai/market/gemini/gemini-2-5-flash).

## Проверки

```sh
python -m unittest discover -s tests -v
```

Для проверки реальной генерации создайте задачу через `POST /cards` с
`n_cards=1` и дождитесь `done` по `GET /crads/{job_id}`. Такая проверка обращается
к внешнему API и расходует кредиты. Одного успешного ответа на текстовый запрос
недостаточно для проверки всей джобы.
